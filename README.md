# Remote Customer Onboarding System

## Project Overview

This project is a system analysis and database design project focused on remote customer onboarding.

The system manages the onboarding journey of a customer from application creation to identity verification, address information, payment method selection, and final account activation.

The main goal was to design a structured system that supports digital onboarding, reduces manual tracking, and keeps customer, application, verification, and payment-related data organized.

---

## Business Problem

Remote onboarding can become complex when customer information, verification steps, address data, and payment options are handled separately.

Without a structured system, it becomes difficult to track:
- customer applications
- verification status
- supported payment methods
- address and location data
- incomplete or failed onboarding attempts

This project was designed to model a more organized and trackable onboarding process.

## Key Business Logic

One important rule in the system is the payment and verification flow.

If the customer’s device supports NFC, the onboarding process can continue through NFC-based verification.

If NFC is not supported, the customer can continue with a bank transfer-based verification/payment flow.

This makes the system more flexible and allows customers with different device capabilities to complete onboarding.
